# Comptoir du Kinah

Suivi communautaire des prix de l'hôtel des ventes d'Aion 2.

- Front : Vite + TypeScript, déployé sur GitHub Pages (`.github/workflows/deploy.yml`)
- Données et connexion Discord : Supabase (`supabase/001_schema.sql`)

Développement local : copier `.env.example` en `.env.local`, le remplir, puis `npm ci` et `npm run dev`.
